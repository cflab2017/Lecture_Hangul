# 기초 3강 — 한글 들여쓰기 (첫 줄 들여쓰기 · 내어쓰기 · Shift+Tab 빠른 내어쓰기)

- 강의: https://www.coding-now.com/blog/hangul/hangul-basic-03-indent

## 파일

| 파일 | 내용 |
|---|---|
| `실습.hwpx` | 따라 할 파일 — 가상 '11월 사내 교육 안내'(첫 문단은 띄어쓰기 두 칸으로 민 상태, 번호 항목 내어쓰기 없음) |
| `정답.hwpx` | 본문 첫 줄 들여쓰기 10pt + 번호 항목 내어쓰기 14.9pt('1. ' 폭) |
| `들여쓰기_비교.pdf` | 같은 문단을 보통 · 들여쓰기 10/20pt · 내어쓰기 20pt · 띄어쓰기 두 칸 · 왼쪽 여백 20pt · 번호 항목(내어쓰기 없음/있음)으로 놓아 한글 2024 가 저장한 PDF |
| `make_files.py` → `measure.json` | 위 세 파일을 한글 2024 자동화로 만들고 PDF 에서 문단마다 첫 줄 · 둘째 줄 시작 위치(mm)를 잰다 |
| `webhwp.json` | 네이버 MYBOX 웹 한글(한컴오피스 Web)에서 연 화면에서 읽은 값 — 문단 모양 값, Shift+Tab 결과 |
| `crop_web.py` | 강의 페이지용 그림을 만든 스크립트(웹 한글 화면 `shots/` 는 저장소에 올리지 않음) |

`make_files.py` 는 Windows + 한글 2024 + `pip install pywin32 pymupdf` 에서 돈다. 한글을 창 없이 띄워 쓰고, %TEMP% 에 저장한 뒤 이 폴더로 복사한다(밖에 바로 저장하면 '파일 접근 허용' 창이 뜬다).

## 핵심

- 문단 모양(Alt+T) [기본] 탭 첫 줄: 보통 · 들여쓰기 · 내어쓰기. 10pt 글자 문단에서 들여쓰기 10pt = 첫 줄 3.51mm, 20pt = 7.06mm.
- 내어쓰기 20pt = 첫 줄 그대로, 둘째 줄부터 7.06mm. 왼쪽 여백 20pt = 모든 줄 7.06mm.
- 띄어쓰기 두 칸으로 민 첫 줄도 3.51mm — 겉보기는 들여쓰기 10pt 와 같지만 글자로 남는다.
- '1. 신청: …' 의 '신청' 앞에서 Shift+Tab(빠른 내어쓰기) → 둘째 줄이 '신청' 아래로. 웹 한글 문단 모양에는 내어쓰기 13.7pt, 한글 2024 PDF 의 '1. ' 폭은 14.9pt(5.24mm).
- 도움말 단축키: 첫 줄 들여쓰기 Ctrl+F6 · 첫 줄 내어쓰기 Ctrl+F5 · 표 안 빠른 내어쓰기 Ctrl+Shift+Tab.
