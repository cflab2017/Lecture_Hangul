# 기초 7강 — 한글 자간 · 장평 (한두 글자만 넘어간 줄 당기기, 글자 모양 Alt+L, 단축키 Alt+Shift+N · W · J · K)

- 강의: https://www.coding-now.com/blog/hangul/hangul-basic-07-letter-spacing

## 파일

| 파일 | 내용 |
|---|---|
| `실습.hwpx` | 따라 할 파일 — 가상 '가을 독서 모임 안내'. 안내 문단(함초롬바탕 10pt)이 4줄이고 마지막 줄에 '요.' 두 글자만 넘어가 있음 |
| `정답.hwpx` | 안내 문단에 자간 -3 %(언어 대표) — 3줄 |
| `measure.py` → `measure.json` | 같은 문단을 자간 · 장평만 바꿔 여러 벌 넣고 한글 2024 PDF 로 줄 수 · 마지막 줄 · 낱말 폭을 잼(실습 · 정답 파일도 여기서 만듦) |
| `measure_lib.py` | 한글 2024 자동화 · HWPX 글자 모양(charPr ratio · spacing) 고치기 · PDF 줄 읽기 공용 |
| `calib.py` → `calib.json` | 안내 문단 길이 고르기 — 마지막 줄에 두 글자만 남는 문장 찾기 |
| `webhwp.json` · `crop_web.py` | 네이버 MYBOX 웹 한글에서 누른 결과(글자 모양 창 값 · 단축키 Alt+Shift+N · W · J · K)와 강의 그림 만들기(`shots/`, 저장소에는 올리지 않음) |

이 PC 한글 2024 는 구독이 없어 편집 동작(HAction.Run)이 False 라, 글자 모양은 HWPX 안 Contents/header.xml 의 charPr 을 복사 · 고쳐 문단에 붙이고 한글로 다시 열어 PDF 로 잰다.
%TEMP% 밖에 저장하면 '파일 접근 허용' 창이 떠서 임시 폴더에 저장 후 복사한다. `pip install pywin32 pymupdf pillow`.

## 핵심

- 기본 4줄(마지막 줄 '요.') → 자간 -1 · -2 % 4줄, **-3 · -4 · -5 % 3줄**, -10 % 3줄 / 장평 99 · 98 % 4줄, **97 · 96 · 95 % 3줄**, 90 % 3줄 / 자간 +10 % 4줄(마지막 줄 12자).
- 웹 한글: Alt+L 글자 모양 — 언어 대표 · 장평 100 % · 자간 0 %. Alt+Shift+N 한 번 -1 %, 세 번 -3 %(3줄) · W 세 번 0 %(4줄) · J 세 번 장평 97 %(3줄) · K 세 번 100 %(4줄).
- 한글 · 영문 섞인 문장(10pt): 기본 '공지' 19.37pt · 'Notice' 30.64pt → 한글만 자간 -15 % 17.93 · 30.64(영문 그대로) → 모든 언어 -15 % 17.93 · 26.81.
- 데스크톱 PDF 와 웹 한글은 줄이 나뉘는 자리가 한두 글자 달랐지만 3줄이 되는 문턱은 같았다.
