# 기초 2강 — 한글 줄간격 (기본 160% 바꾸기 · 줄간격 줄이기·넓히기 · 글자가 겹칠 때)

- 강의: https://www.coding-now.com/blog/hangul/hangul-basic-02-line-spacing

## 파일

| 파일 | 내용 |
|---|---|
| `실습.hwpx` | 따라 할 파일 — 가상 '지하 주차장 바닥 도색 작업 안내', 본문 100%, 마지막 알림 문단 고정 값 7pt(글자 겹침) |
| `정답.hwpx` | 본문 글자에 따라 160%, 알림 문단 200% |
| `줄간격_비교.pdf` | 같은 문단을 160% · 100% · 200% · 0% · 고정 값 20pt · 고정 값 7pt · 최소 7pt · 여백만 지정 0pt 로 놓은 비교 쪽(한글 2024) |
| `make_files.py` → `measure.json` | 위 파일을 한글 2024 자동화로 만들고, PDF 글자 위치로 줄 윗부분 사이 거리(pt)를 잰 스크립트 |
| `crop_web.py` | 강의 페이지 그림(비교 PDF · 웹 한글 문단 모양 창)을 만든 스크립트(`shots/` 는 올리지 않음) |

스크립트는 Windows + 한글 2024 + `pip install pywin32 pymupdf` 에서 돈다. 한글 자동화는 %TEMP% 밖에 저장하려 하면 '파일 접근 허용' 창을 띄워서, 임시 폴더에 저장한 뒤 복사한다.

## 핵심 (글자 10pt)

- 글자에 따라 160% = 줄 윗부분 사이 16pt, 100% = 10pt, 200% = 20pt, 0% = 세 줄이 한 줄에 겹침.
- 고정 값 7pt = 6.95pt — 글자보다 작아 줄마다 3pt 쯤 겹침. 최소 7pt = 10pt(글자보다 작게는 안 줄어듦). 여백만 지정 0pt = 10pt.
- 자동화(HParaShape.LineSpacing)로 고정 계열 값을 넣으면 저장 값이 절반이 됐다 — pt × 200 으로 넣는다.
- 단축키 Alt+Shift+A 좁게 · Alt+Shift+Z 넓게(10%씩, 한글 도움말), 문단 모양 Alt+T.
