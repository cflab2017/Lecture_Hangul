# 기초 1강 — 한글 단축키 (자주 쓰는 34가지 · Ctrl+N,T 누르는 법 · 웹 한글에서 다른 키)

- 강의: https://www.coding-now.com/blog/hangul/hangul-basic-01-shortcuts

## 파일

| 파일 | 내용 |

## 핵심

- '+' 는 함께, ',' 는 떼고 다음: Alt+L 은 동시에, Ctrl+N,T 는 Ctrl+N 을 눌렀다 뗀 뒤 T.
- 웹 한글은 브라우저 단축키가 먼저 — 크롬의 Ctrl+N(새 창). 웹 한글 도움말은 표 만들기를 Alt+N,T 로도 적는다.
- 워드와 같은 키, 다른 뜻: Ctrl+E(워드 가운데 · 한글 지우기), Ctrl+L(왼쪽 · 다시 찾기), Ctrl+J(양쪽 · 쪽 나누기), F7(맞춤법 · 편집 용지).
