# 기초 8강 — 한글 PDF 변환 (PDF로 저장하기, 그대로 가는 것과 따라가는 지은이 정보)

- 강의: https://www.coding-now.com/blog/hangul/hangul-basic-08-save-as-pdf

## 파일

| 파일 | 내용 |
|---|---|
| `실습.hwpx` | 따라 할 파일 — 가상 마을 도서관 11월 소식, 2쪽(2쪽은 쪽 나누기로 시작) · 쪽 번호(아래 가운데) · 하이퍼링크 하나(2쪽 끝 '코딩나우'). 1쪽 누리집 주소는 글자로만 씀 |
| `정답.pdf` | 실습 파일을 한글 2024 에서 PDF 로 저장한 것 — 2쪽 · A4 · 링크 1개 · 글꼴 포함(문서 정보 만든 이를 CODINGNOW 로 고친 사본) |
| `measure.py` → `measure.json` | 실습 파일을 만들고 한글 2024(창 숨김)로 PDF 저장 → 쪽 수 · 용지 · 글꼴 · 링크 · 쪽 번호 · 문서 정보 · 크기를 pymupdf 로 읽음. HWP 로 저장한 것 · 저장 안 한 새 문서의 PDF 도 비교 |
| `crop_web.py` | 정답.pdf 의 1 · 2쪽을 강의 그림으로 |

스크립트는 Windows + 한글 2024 + `pip install pywin32 pymupdf pillow` 에서 돈다. %TEMP% 밖에 저장하면 '파일 접근 허용' 창이 떠서 임시 폴더에서 만들고 끝에 이 폴더로 복사한다.
웹 한글(MYBOX)에서 PDF 로 저장하는 것은 이번에 재지 않았다.

## 핵심(이 PC 한글 2024, 13.0.0.4132)

- PDF: 2쪽 · 595 × 841pt(A4) · 쪽 번호 '- 1 -' · '- 2 -' · 글꼴 HCRBatang · HCRDotum 포함(Type0, 부분 포함) · 본문 문장 그대로 추출 · 링크 1개(하이퍼링크로 넣은 것만, 글자로 쓴 https:// 는 링크 아님).
- 크기: HWPX 34,431 · HWP 23,040 바이트 → PDF 31,059 · 31,058 바이트(같은 결과).
- PDF 지은이 = 한글 문서 정보의 지은이(실습 파일 CODINGNOW → PDF CODINGNOW, 저장 안 한 새 문서 → 지은이 없음). 만든 프로그램 Hwp 2024 13.0.0.4132, PDF 생성기 Hancom PDF 1.3.0.550.
