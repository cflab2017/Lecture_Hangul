# 기초 4강 — 한글 특수문자 · 문자표 (Ctrl+F10, 여러 개 한 번에 넣기, 비슷한 기호 구별)

- 강의: https://www.coding-now.com/blog/hangul/hangul-basic-04-special-characters

## 파일

| 파일 | 내용 |
|---|---|
| `실습.hwpx` | 따라 할 파일 — 가상 '동아리 11월 정기 모임 안내', 기호 없이 쓴 상태 |
| `정답.hwpx` | ★ ▶ ㎡ ① ② ③ ※ ☎ 를 넣은 안내 |
| `기호_비교.pdf` | 생김새가 비슷한 짝(가운뎃점 · / 아래아 ㆍ, ① / (1), ㈜ / (주), × / x)을 같은 글꼴로 놓고 한글 2024 가 저장한 PDF |
| `make_files.py` → `measure.json` | 위 세 파일을 한글 2024 자동화로 만들고 PDF 에서 글자 폭(pt)을 잰다 |
| `charmap_web.json` | 네이버 MYBOX 웹 한글(한컴오피스 Web v2) 문자표의 문자 영역 18개를 하나씩 눌러 읽은 글자 목록 |
| `webhwp.json` | 웹 한글에서 해 본 결과 — Ctrl+F10, 누를 때마다 입력 문자에 이어 붙음, 넣기 한 번에 여러 글자, 최근 사용한 문자, Ctrl+Z, 코드 입력(Alt+Shift+F10) |
| `crop_web.py` | 강의 페이지용 그림을 만든 스크립트(웹 한글 화면 `shots/` 는 저장소에 올리지 않음) |

`make_files.py` 는 Windows + 한글 2024 + `pip install pywin32 pymupdf` 에서 돈다. 한글을 창 없이 띄워 쓰고, %TEMP% 에 저장한 뒤 이 폴더로 복사한다(밖에 바로 저장하면 '파일 접근 허용' 창이 뜬다).

## 핵심

- 문자표 Ctrl+F10(입력 → 문자표) — 한글 2024 도움말 단축키 표 · 웹 한글에서 열림 확인.
- 웹 한글 문자표: 문자 영역 18개(일반 문장 부호 · 기호1 · 기호2 · 통화 기호 · 글자 모양 기호 · 숫자 형식 · 화살표 · 괄호 · 수학 연산자 · 그리스어 · 단위기호 · 원문자 · 괄호문자 · 상자 그리기 · 도형 · 기타 기호 · 한중일 기호 및 구두점 · 호환용 한글 자모). 데스크톱 도움말의 네 탭(사용자 · 유니코드 · 한글(HNC) · 완성형(KS))은 없다.
- ★ ☆ ☎ ♥ = 기타 기호, ※ · = 일반 문장 부호, ①~⑳ · ㉑~㊿ = 원문자, ㈜ = 괄호문자(기호2 에도), ㎡ = 단위기호, ▶ = 도형 · 기호2.
- 글자 칸을 누를 때마다 입력 문자 끝에 붙는다(★ → ★☆, ☎ 두 번 → ★☆☎☎). 넣기 → 네 글자가 한꺼번에(130 → 134 글자). 다시 열면 최근 사용한 문자 ☎ ☆ ★. Ctrl+Z 한 번에 네 글자 모두 지워짐.
- 함초롬바탕 10pt 글자 폭: 가운뎃점 · (U+00B7) 3.19pt, 아래아 ㆍ (U+318D) 9.66pt, ① 9.66pt, ㈜ 9.66pt(괄호 3.19 + 주 9.66 + 괄호 3.19 = (주) 16.04pt), × 6.14pt · x 5.40pt.
- 웹 한글에서 '2605' 를 친 뒤 Alt+Shift+F10(자동 입력) → 변화 없음. 도움말의 코드 입력은 데스크톱 한글 기준.
- 한자 변환은 이 강에서 뺐다 — 웹 한글에는 한자 바꾸기가 없고(메뉴 없음, F9 무반응), 이 PC 한글 2024 는 편집이 막혀(구독) 잴 수 없었다.
