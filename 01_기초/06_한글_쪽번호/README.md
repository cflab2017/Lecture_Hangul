# 기초 6강 — 한글 쪽 번호 (쪽 번호 매기기, 표지 감추기, 2쪽부터 1, 웹 한글은 꼬리말에서)

- 강의: https://www.coding-now.com/blog/hangul/hangul-basic-06-page-numbers

## 파일

| 파일 | 내용 |
|---|---|
| `실습.hwpx` | 따라 할 파일 — 가상 봉사 동아리 보고서, 1쪽 표지 + 본문 2쪽, 쪽 번호 없음 |
| `정답.hwpx` · `정답.pdf` | 가운데 아래 쪽 번호(줄표) · 1쪽 현재 쪽만 감추기 · 2쪽 첫 줄에서 새 번호 1 → 1쪽 없음 · 2쪽 - 1 - · 3쪽 - 2 - |
| `measure.py` → `measure.json` | 한글 2024 자동화로 다섯 경우를 PDF 로 저장해 쪽 아래 글자(번호)를 읽은 값, 실습 · 정답 파일도 만든다 |
| `webhwp.json` | 네이버 MYBOX 웹 한글에서 잰 것 — 쪽 메뉴에 '쪽 번호 매기기'가 없고 꼬리말 ▸ 가운데 쪽 번호, 커서 쪽부터 적용, 감추기는 '꼬리말'을 체크해야 함, 새 번호로 시작 창 |
| `crop_web.py` | 강의 그림(`shots/` 원본은 저장소에 올리지 않음) — 웹 한글은 창 전체 + 빨간 테두리 + 확대, 정답 PDF 세 쪽 |

스크립트는 Windows + 한글 2024 + `pip install pywin32 pymupdf pillow` 에서 돈다. %TEMP% 밖에 저장하면 '파일 접근 허용' 창이 떠서 임시 폴더에 저장한 뒤 복사한다. HWPX 작성자 · PDF 메타데이터는 CODINGNOW.

## 핵심

- 이 PC 한글 2024 는 구독이 없어 HAction.Run 편집 동작은 False 지만, HAction.Execute 로 쪽 번호 매기기(PageNumPos) · 현재 쪽만 감추기(PageHiding, 쪽 번호) · 새 번호로 시작(NewNumber)은 됐다. 표지 뒤 쪽 나누기는 HWPX `pageBreak="1"`.
- 데스크톱(PDF): 쪽 번호 매기기 → - 1 - · - 2 - · - 3 - / 1쪽 감추기 → 없음 · - 2 - · - 3 - / + 2쪽에서 새 번호 1 → 없음 · - 1 - · - 2 - / 커서가 2쪽일 때 감추기 → - 1 - · 없음 · - 3 - / 새 번호 5 → - 5 - · - 6 - · - 7 - / 줄표 없이 → 1 · 2 · 3.
- 웹 한글: 쪽 메뉴에 쪽 번호 매기기가 없고 쪽 → 꼬리말 ▸ 왼쪽 · 가운데 · 오른쪽 쪽 번호. 커서가 3쪽일 때 넣자 1 · 2쪽엔 번호 없음, 3쪽만 3. 꼬리말로 넣은 번호는 현재 쪽만 감추기에서 '쪽 번호'를 체크해도 그대로 — '꼬리말'을 체크해야 사라짐(창 안내문과 같음).
